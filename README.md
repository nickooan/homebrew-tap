# homebrew-tap

Homebrew tap for [nickooan](https://github.com/nickooan)'s tools.

## Install

```bash
brew install --cask nickooan/tap/ntee
```

## Available casks

| Cask | Description |
|---|---|
| [`ntee`](https://github.com/nickooan/ntee-editor) | Terminal text editor with LSP, git diff review, and conflict solving |

The cask definitions in `Casks/` are generated and pushed automatically by
[GoReleaser](https://goreleaser.com) when a release is tagged in the source
repository — do not edit them by hand.
